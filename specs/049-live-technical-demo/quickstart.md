# Quickstart
Use Node 22 and installed npm dependencies/Playwright Chromium.
1. `npm run demo:start` (builds then starts local-only app/provider).
2. `npm run demo:reset` resets fictional placement records.
3. Open http://127.0.0.1:3100/login; fictional email recruiter@example.test and local mock code 001234.
4. `npm run demo:verify` runs focused verification and generates evidence.
5. `npm run demo:capture` captures real corrected-app screenshots.
6. Follow `docs/engineering/live-demo/script.md` for the 15-minute technical sequence.
Ctrl-C stops the demo. Never run the Blob seed for this demo. Full verification is documented in the feature verification report.
