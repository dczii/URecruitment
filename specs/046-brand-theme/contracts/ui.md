# UI contract

Shared semantic names remain stable. Light surface = white, primary = logo red, text = near-black. Dark surfaces = neutral-black with readable lighter-red actions. The USER logo always has a white backing. Active navigation retains aria-current and indicator; statuses retain existing text/icons/aria labels. Due-soon is outlined; overdue uses the red status pair. Destructive focus uses an opaque ring. Inline content links and link-buttons are underlined. Existing screen layouts, action labels, typed-name safeguards and EN/ZH fonts are preserved.

Text contrast >=4.5:1; meaningful borders/focus >=3:1. Never rely on color alone. No component-local hex values. Chart series have independent theme variables; future charts need labels/patterns. Visual pen documents are not claimed synchronized.
